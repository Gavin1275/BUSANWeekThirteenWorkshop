# Data Dictionary

# Dataset: week13_employee.csv

| Name                    | Description                                                                                                                        |
|-------------------|-----------------------------------------------------|
| Attrition               | Whether the employee is leaving the company                                                                                        |
| Department              | Department of employment                                                                                                           |
| JobRole                 | Job title                                                                                                                          |
| FTE                     | Full-time equivalent value (1 = full-time)                                                                                         |
| StandardHours           | Standard weekly hours                                                                                                              |
| BusinessTravel          | Frequency of business travel                                                                                                       |
| HourlyRate              | Annual salary expressed as hourly rate                                                                                             |
| PercentSalaryHike       | Percentage increase in salary relative to last year                                                                                |
| StockOption             | Whether the employee has an option of buying the company's shares at a set price                                                   |
| TrainingTimesLastYear   | Number of training sessions the employee attended last year                                                                        |
| YearsAtCompany          | Number of years the employee has been at the company                                                                               |
| YearsInCurrentRole      | Number of years the employee has been at their current role                                                                        |
| YearsSinceLastPromotion | Number of years since the employee's last promotion                                                                                |
| YearsWithCurrManager    | Number of years the employee has been with their current line manager                                                              |
| Age                     | Employee age                                                                                                                       |
| Gender                  | Employee gender                                                                                                                    |
| MaritalStatus           | Employee marital status                                                                                                            |
| EducationField          | Employee's field of education                                                                                                      |
| NumCompaniesWorked      | Number of companies the employee has previously worked for                                                                         |
| TotalWorkingYears       | Number of years of working experience the employee has to date                                                                     |
| PerformanceRating       | Line manager's rating of employee performance (1 = Unsatisfactory, 2 = Satisfactory, 3 = Above expectation, 4 = Exceed standards) |
| SatisfactionJob         | Employee self-rated level of job satisfaction (1 = Low, 2 = Medium, 3 = High, 4 = Very High)                                       |
| SatisfactionDecision    | Employee self-rated level of satisfaction with involvement in decision-making (1 = Low, 2 = Medium, 3 = High, 4 = Very High)       |
| SatisfactionEnvironment | Employee self-rated level of satisfaction with the work environment (1 = Low, 2 = Medium, 3 = High, 4 = Very High)                 |
| SatisfactionManager     | Employee self-rated level of satisfaction with their line manager (1 = Low, 2 = Medium, 3 = High, 4 = Very High)                   |
| SatisfactionWorkLife    | Employee self-rated level of satisfaction with their work-life balance (1 = Low, 2 = Medium, 3 = High, 4 = Very High)              |
