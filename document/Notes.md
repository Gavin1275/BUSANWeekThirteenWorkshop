# General Notes / Guidance When Conducting Analysis

You can use GenAI tools for brainstorming, coding, or software assistance.

## 1.	Initial setup

 - Set up a project folder for this exercise that includes all relevant files downloaded from GitHub.
 - Install and load packages, and import and preview data. Can copy code chucks from prior lab demonstrations.
 - Transform the outcome variable and specify the factor level order.

## 2. Explore the data to understand more about it and conduct preliminary analysis to identify factors that may influence employee attrition

 - Conduct common data preparation checks to get insights on what steps should be added to the machine learning workflow recipe.
 - Conduct exploratory data analysis and appropriate bivariate analysis.

## 3. Apply the machine learning workflow to build classification models

 - Try different preprocessing techniques, including principal component analysis.
 - Try different algorithms.
 - Select an appropriate performance metric to tune and evaluate model performance.

## 4. Assess the out-of-sample performance of your best classification model and consider whether it can be relied on for identifying employee attrition.

 - Consider whether the model is underfitting and/or overfitting.
